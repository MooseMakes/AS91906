# General Information:
Tutor Tower is an educational quiz game application created using Python, SQLite, and Tkinter.

## Installation & Access:
In order to run the program, the user must have installed Python*.

## Usage:
The user is required to create an account or log in to an existing account in order to access the main menu. The main menu allows the user to:

- View usage instructions
- View update log
- Submit feedback
- View statistics
- Buy cosmetic items
- Configure app settings
- View and edit account information
- Sign out of their account
- Exit the app
- Join a game and:
    - Access hints
    - Exit the game and return to the main menu
- Create a game by:
    - Writing questions, answers, and hints
    - Assigning difficulty
    - Configuring game settings
